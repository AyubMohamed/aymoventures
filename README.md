# aymoventures.ca

The holding page for **AYMO Ventures Inc.**, served by GitHub Pages from `main`.

- `index.html` — the whole site. No build step, no dependencies.
- `404.html` — the same shell, different words.
- `CNAME` — the custom domain. GitHub reads this file; do not rename it.

To change the copy, edit `index.html` and push. Pages redeploys in about a minute.
